

### WarehouseControl

Мини-система для учёта товаров на складе с поддержкой ролевой модели, логированием изменений и JWT-аутентификацией.  
Использует **PostgreSQL** с **триггерами** для логирования изменений (антипаттерн, как указано в задании).


---

### 1. Клонировать репозиторий

```sh
git clone https://github.com/v1adis1av28/Level3.git
cd Level3/WarehouseControl
```

### 2. Запустить Docker

```sh
docker-compose up --build
```

Сервис поднимется на:

**[http://localhost:8080](http://localhost:8080)**

---

###  Функционал

- **CRUD-операции** для товаров.
- **История изменений** с указанием, кто, что, когда и зачем изменил.
- **модели прав доступа**:
  - `admin` — полный доступ.
  - `manager` — просмотр и редактирование.
  - `viewer` — только просмотр.
- **JWT-аутентификация** с ролью в токене.

---

### API 

| Метод | Путь | Описание | Роли |
|-------|------|----------|------|
| `POST` | `/auth/login` | Вход (регистрация пользователя в системе) | Все |
| `POST` | `/items` | Добавить товар | `admin`, `manager`, `viewer` |
| `GET` | `/items` | Получить список товаров | Все |
| `PUT` | `/items/{id}` | Обновить товар | `admin`, `manager` |
| `DELETE` | `/items/{id}` | Удалить товар | `admin` |
| `GET` | `/items/{id}/history` | История изменений товара | Все |

---

### Форматы данных

#### Вход (`/auth/login`)

```json
{
  "username": "string",
  "role": "admin | manager | viewer"
}
```

#### Товар (`/items`)

```json
{
  "id": 1,
  "name": "string",
  "description": "string",
  "quantity": 0
}
``````
