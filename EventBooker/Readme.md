## EventBooker

## Для запуска 
```
    #склонируйте репозиторий и перейдите в каталог с проектом
    docker-compose up --build
```

## Тестирование 

После запуска можно протестировать на фронтенде

- localhost:8080/static/user.html
- localhost:8080/static/admin.html

На странице админа можно создать ивент указать всю необходимую информацию

На странице пользователя можно найти сам ивент и сделать бронь, а также сразу подтвердить ее
